# Fine-Tuning DNABERT-2 for Pathogenicity Classification of HBB Gene Variants

Fine-tunes DNABERT-2, a pretrained genomic language model, to classify the pathogenicity
(benign vs. pathogenic) of variants in the human HBB gene, associated with sickle cell
disease and beta-thalassemia. Also investigates whether jointly learning a five-class
mutation-type objective (Intron, Missense/in-frame, Protein-truncating/splice-disrupting,
Synonymous, UTR) as an auxiliary task improves pathogenicity classification.

Status: working paper, in preparation.

## Overview

- **Data source:** ClinVar (HBB-linked variant records, TSV + VCF) and the GRCh38
  human reference genome.
- **Backbone model:** DNABERT-2 (117M parameters, byte-pair-encoded tokenization).
- **Task 1 (primary):** Binary pathogenicity classification.
- **Task 2 (auxiliary, ablated):** 5-class mutation-type classification, jointly
  trained via a weighted loss `L = L_pathogenicity + beta * L_mutation_type`.
- **Validation approach:** 70/10/20 stratified train/val/test split, beta selected
  via validation-set ablation, 5-seed robustness evaluation, per-mutation-class and
  confusion-matrix analysis.

## Key results (5-seed mean ± std, held-out test set, n=223)

| Model | AUROC | F1 | MCC |
|---|---|---|---|
| Single-Task Baseline | 0.897 ± 0.004 | 0.671 ± 0.075 | 0.555 ± 0.094 |
| Multi-Task (beta=0.5) | 0.898 ± 0.005 | 0.694 ± 0.017 | 0.586 ± 0.021 |

Multi-task training did not improve AUROC (ranking ability) but reduced the average
number of missed pathogenic variants from 15.6 to 5.4, and substantially reduced
run-to-run variance in F1/MCC. Paired t-tests across seeds did not reach conventional
significance thresholds (p > 0.4 for all metrics); this is reported honestly as a
directional, mechanistically-explained finding rather than a statistically confirmed one.

## Pipeline summary

1. Filter ClinVar HBB records to clean SNV/indel variant types and unambiguous
   germline classifications (benign/likely-benign vs. pathogenic/likely-pathogenic).
2. Map raw molecular consequence annotations into 5 mutation-type classes.
3. Extract 501bp REF/ALT sequence windows from GRCh38, with reference-allele
   verification against the genome.
4. Stratified 70/10/20 train/val/test split (stratified jointly on pathogenicity
   and mutation type), with duplicate/leakage checks.
5. Fine-tune DNABERT-2 (single-task and multi-task configurations).
6. Beta ablation on the validation set; 5-seed evaluation on the held-out test set.
7. Evaluate: AUROC/F1/MCC for pathogenicity, accuracy/macro-F1/per-class metrics
   for mutation type, confusion matrices for both tasks, per-mutation-class
   pathogenicity breakdown.

## Reproducing this pipeline

1. Obtain a ClinVar variant summary TSV and VCF filtered to HBB (NCBI ClinVar FTP
   or web export).
2. Obtain the GRCh38 human reference genome FASTA (e.g. from Ensembl or UCSC).
3. Install dependencies: `pip install -r requirements.txt`
4. Open `HBB_ClinVar_Pipeline.ipynb` and run cells top to bottom. A GPU runtime
   (CUDA or Colab T4) is strongly recommended; the beta ablation and 5-seed
   evaluation are compute-intensive on CPU/MPS.

## Model

[DNABERT-2](https://github.com/MAGICS-LAB/DNABERT_2) (Zhou et al., ICLR 2024),
loaded via HuggingFace `transformers` with `trust_remote_code=True`.
